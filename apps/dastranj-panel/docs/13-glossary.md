# واژه‌نامه

## 1. هدف

این واژه‌نامه برای یکدست شدن زبان محصول و جلوگیری از برداشت‌های متفاوت نوشته شده است.

## 2. واژه‌ها

| واژه | معنی ساده |
| --- | --- |
| کسب‌وکار | سازمان یا مجموعه‌ای که از پنل برای مدیریت عملیات خود استفاده می‌کند |
| tenant | اکانت یا فضای مستقل یک کسب‌وکار در سیستم |
| صاحب کسب‌وکار | فرد اصلی مسئول کسب‌وکار |
| مالک اکانت کسب‌وکار | فرد یا نهاد صاحب حساب عملیاتی کسب‌وکار |
| محل کار | مکان فیزیکی یا سایت کاری |
| تقویم کاری | برنامه سالانه یا دوره‌ای روزهای کاری و تعطیلی |
| قالب شیفت | الگوی آماده برای تعریف ساعت کار |
| سیاست کاری | مجموعه قواعد حضور، مرخصی، تأخیر و رفتار عملیاتی |
| گروه کاری | گروه اجرایی شامل افراد، محل و سیاست مشترک |
| واحد سازمانی | بخش داخلی سازمان مثل منابع انسانی یا مالی |
| کارمند | فردی که در سازمان ثبت و مدیریت می‌شود |
| درخواست | تقاضای رسمی کارمند برای مرخصی، تردد، وام و موارد مشابه |
| قرارداد پیش‌نویس | نسخه در حال تکمیل قرارداد قبل از نهایی‌شدن |
| قالب پیش‌نویس قرارداد | الگوی آماده برای ساخت قراردادهای مشابه |
| حقوق و دستمزد | قواعد و محاسبات مالی مربوط به پرداخت به نیروها |
| مزایا | پرداخت‌ها یا امتیازهای افزاینده در محاسبه مالی |
| کسورات | موارد کاهنده در محاسبه مالی |
| تردد | ثبت حضور، ورود، خروج یا اصلاح آن |
| راه‌اندازی سریع | مسیر کوتاه برای رسیدن به حداقل تنظیمات لازم |
| وضعیت تکمیل تنظیمات | نشان می‌دهد کدام بخش‌های حیاتی کامل شده‌اند و کدام‌ها هنوز باقی مانده‌اند |

## 3. نکته

این واژه‌ها باید در کل مستندات با همین معنا استفاده شوند تا تیم محصول، کسب‌وکار و QA یک زبان مشترک داشته باشند.
