## 📊 داده‌ها

### وضعیت فعلی: Mock Data
تمام داده‌ها Mock هستند و با `setTimeout` شبیه‌سازی می‌شوند.

### برای اتصال به API:
در هر کامپوننت، بخش `useEffect` را پیدا کنید و `setTimeout` را با `fetch` جایگزین کنید:

```typescript
// قبل (Mock)
useEffect(() => {
  setTimeout(() => {
    setData([...mockData]);
    setLoading(false);
  }, 500);
}, []);

// بعد (API)
useEffect(() => {
  fetch('/api/customer/contracts')
    .then(res => res.json())
    .then(data => {
      setData(data);
      setLoading(false);
    });
}, []);
```
