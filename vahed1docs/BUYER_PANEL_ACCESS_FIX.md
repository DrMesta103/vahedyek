# رفع مشکل نمایش دسترسی‌های پنل خریدار

## 🐛 مشکل
کلیک روی دکمه "فعال کردن دسترسی" در بخش تنظیمات هیچ اتفاقی نمی‌افتاد و گروه "پنل خریدار" نمایش داده نمی‌شد.

## 🔍 علت مشکل
در فایل `AccessManagementPanel.tsx`، آبجکت `GROUP_LABELS` فقط شامل 4 گروه بود:
```typescript
const GROUP_LABELS: Record<string, string> = {
  platform: 'پنل و کاربران',
  business: 'کسب و کار',
  complex: 'مجتمع',
  contracts: 'قراردادها',
  // ❌ customer گم بود!
};
```

بنابراین وقتی دسترسی‌های گروه `customer` از API دریافت می‌شدند، برچسب فارسی برای آن‌ها وجود نداشت و در UI نمایش داده نمی‌شدند.

## ✅ راه‌حل
گروه `customer` با برچسب فارسی به `GROUP_LABELS` اضافه شد:

```typescript
const GROUP_LABELS: Record<string, string> = {
  platform: 'پنل و کاربران',
  business: 'کسب و کار',
  complex: 'مجتمع',
  contracts: 'قراردادها',
  customer: 'پنل خریدار', // ✅ اضافه شد
};
```

## 📁 فایل تغییر یافته
```
apps/vahedyek-panel/app/(panel)/business-settings/_components/AccessManagementPanel.tsx
```

## 🎯 نتیجه
حالا در صفحه تنظیمات (`http://localhost:3000/settings`):

1. ✅ گروه **"پنل خریدار"** نمایش داده می‌شود
2. ✅ تمام 11 دسترسی پنل خریدار قابل مشاهده هستند
3. ✅ کلیک روی دکمه‌های "فعال کردن" کار می‌کند
4. ✅ می‌توانید دسترسی‌ها را به نقش‌ها اختصاص دهید

## 📋 دسترسی‌های قابل مشاهده در گروه "پنل خریدار"

1. دسترسی به پنل خریدار
2. مشاهده قراردادهای خود
3. مشاهده جزئیات قرارداد
4. مشاهده اطلاعات مالی
5. مشاهده پرداخت‌ها
6. ثبت فیش پرداختی
7. مشاهده اسناد و مدارک
8. مشاهده تیکت‌های پشتیبانی
9. ایجاد تیکت پشتیبانی
10. مشاهده پروفایل
11. ویرایش پروفایل

## 🧪 تست
برای تست کردن:

1. به `http://localhost:3000/settings` بروید
2. یک نقش جدید با عنوان "خریدار" ایجاد کنید
3. در لیست گروه‌ها، گروه **"پنل خریدار"** را پیدا کنید
4. روی دکمه "فعال کردن همه" کلیک کنید
5. تمام 11 دسترسی باید فعال شوند ✅

1. **ایجاد نقش خریدار:**
   - به تنظیمات بروید
   - نقش جدید با عنوان "خریدار" ایجاد کنید

2. **اختصاص نقش:**
   - در بخش "تخصیص نقش به اعضا"
   - نقش "خریدار" را به کاربران مورد نظر اختصاص دهید

3. **تست:**
   - با یک کاربر با نقش "خریدار" وارد شوید
