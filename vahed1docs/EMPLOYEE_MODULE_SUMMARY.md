## 🔧 تنظیمات مورد نیاز

### 1. بروزرسانی Prisma Schema

فیلدهای زیر را به مدل `Employee` اضافه کنید:

```prisma
model Employee {
  id        String   @id
  tenantId  String
  firstName String
  lastName  String
  mobile    String?  // 🆕 اضافه کنید
  email     String?  // 🆕 اضافه کنید
  avatarUrl String?  // 🆕 اضافه کنید
  isActive  Boolean  @default(true)
  tenant    Tenant   @relation(fields: [tenantId], references: [id], onDelete: Cascade)
  subjects  ContractSubject[]

  @@index([tenantId])
  @@index([tenantId, mobile]) // 🆕 اضافه کنید
}
```

### 2. اجرای Migration

```bash
cd apps/vahedyek-panel
npx prisma migrate dev --name add_employee_contact_fields
```

### 3. تولید Prisma Client

```bash
npx prisma generate
```

## 🚀 نحوه استفاده

### افزودن کارمند

1. به `/employees` بروید
2. روی "افزودن کارمند" کلیک کنید
3. مراحل ویزارد را طی کنید:
   - موبایل: `09123456789`
   - نام: `علی`
   - نام خانوادگی: `احمدی`
   - ایمیل: `ali@example.com`
4. در صفحه خلاصه بررسی کنید
5. در صورت نیاز آواتار آپلود کنید
6. روی "ثبت کارمند" کلیک کنید

### مدیریت کارمندان

1. در صفحه `/employees`:
   - جستجو کنید
   - وضعیت را تغییر دهید
   - ویرایش یا حذف کنید
